# VanLife

This repository contains my VanLife project as I learn and practice **React Router 6** using the Scrimba course.

I originally worked on this project inside my `learn-react-router-6` course repository. I decided to move it into a separate repository, `van-life`, so I can manage, develop, and deploy my own version of the project independently.

## Purpose

- Practice React Router 6 concepts and routing.
- Learn nested routes, layouts, and navigation.
- Improve my React development skills.
- Deploy and maintain my own version of the project.

This is a learning project, and I will continue updating it as I progress through the course.
