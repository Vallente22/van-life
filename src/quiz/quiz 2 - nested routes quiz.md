1. What is the primary reason to use a nested route?
to share a common layout or UI between related routes while rendering different child pages inside it.


2. What is a "Layout Route"?
a layout route is for showing shared ui like nav bar while showing more parts of a pagee


3. What does the <Outlet /> component do? When do you use it?
<Outlet /> renders the matching child route's component inside its parent layout.


4. What is an "Index Route"?
an index route renders the default child page when the parent route's path matches exactly and no child path is specified.
